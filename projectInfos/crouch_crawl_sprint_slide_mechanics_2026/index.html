Crouch + Crawl + Sprint + Slide Mechanics (2026)

Overview

Used free animations to do it. With help of UserInputService I get input (For mobile users could put a button). After getting input based on some parameters my script decides what to do. For better quality, it sets camera's offset and field of view (fov) [Actually tweens]. For sliding mechanics it uses align orientation and linear velocity and sets their values based on conditions like character is climbing up or down etc.
